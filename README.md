# Eutrophics website redesign

Static, mobile-first marketing site for Eutrophics Lab in Knoxville, Tennessee.

## Source content
The first draft is based on Eutrophics' currently published website/business information and Chris Dixon's public business profile. Before production launch, confirm all pricing, hours, service wording, phone numbers, and clinic locations with the client.

## Run locally
Open `index.html` directly or serve the directory with any static file server.

## GitHub Pages
This site is plain HTML/CSS/JS and can be hosted directly from a GitHub Pages branch or through a GitHub Actions Pages workflow.

## Production handoff checklist
- Replace remote Wix image URLs with original client-owned image files.
- Confirm current service pricing and appointment hours.
- Confirm the exact public street address before adding address schema or a map.
- Add the client's approved privacy notice and any practice-specific legal notices.
- Do not add a medical intake/contact form unless it uses the practice's approved secure/HIPAA-appropriate workflow.
- Point the custom domain only after client approval.
